Langkah membuka game

  1. Unduh atau buka aplikasi dari halaman Akses Game. Jika Drive meminta izin, ajukan akses dan hubungi pendamping.
  2. Pasang / jalankan sesuai platform perangkatmu. Pada Android, izinkan pemasangan dari sumber yang kamu percaya jika diminta.
  3. Masuk ke akun game. Game memiliki login sendiri untuk menyimpan progres dan leaderboard. Akun ini terpisah dari website dan dari kode peserta tes.
  4. Buka Dashboard, pilih mode Campaign untuk belajar bertahap lewat level dan quest, atau Freemode untuk bereksperimen bebas.
  5. Pilih materi: Array, Linked List, Stack, atau Queue. Ikuti instruksi quest dan perhatikan Code Printer yang menampilkan kode dari setiap operasi.

Navigasi di dalam game

  • Dashboard — pintu masuk ke semua mode dan pengaturan.
  • Campaign — pilih level, selesaikan quest berurutan (misalnya: buat array, lalu isi nilainya).
  • Freemode — jalankan operasi apa pun tanpa target.
  • Leaderboard — melihat skor antar pemain.
  • Setting — volume musik dan efek suara.
  • Tombol Home / Back selalu tersedia untuk kembali ke Dashboard.

Jika game tidak bisa dibuka

  • Pastikan file terunduh utuh; unduh ulang bila ukurannya tidak sesuai.
  • Periksa platform perangkat cocok dengan file yang disediakan.
  • Tutup aplikasi lain yang berat, lalu coba lagi.
  • Jika login game gagal, periksa koneksi internet.
  • Masih bermasalah? Catat pesan yang muncul dan hubungi pendamping. Lihat juga Bantuan.

Sudah selesai bermain?

Kembali ke website ini dan kerjakan post-test. Gunakan kode peserta yang sama dengan pre-test agar hasilmu bisa dipasangkan.
