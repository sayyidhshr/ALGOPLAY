Apa itu ALGOPLAY?

Game edukasi berbasis Unity yang memvisualkan struktur data linear, didampingi website ini sebagai pusat materi, akses, dan evaluasi.

Deskripsi

ALGOPLAY adalah media pembelajaran interaktif untuk materi Struktur Data Linear: Array, Linked List, Stack, dan Queue. Di dalam game, setiap struktur ditampilkan dengan metafora benda sehari-hari — gerbong kereta untuk array, tumpukan burger untuk stack, antrean kartu untuk queue — sehingga operasi seperti menambah, menghapus, dan mengakses elemen bisa dilihat langsung, bukan hanya dibayangkan.

Game ini dibangun dengan Unity 2022.3. Fitur yang tersedia meliputi Dashboard untuk memilih materi, mode Campaign yang berisi level dan quest bertahap, mode Freemode untuk bereksperimen bebas, Code Printer yang menampilkan potongan kode dari operasi yang sedang dilakukan, serta Leaderboard. Untuk menyimpan progres, game memiliki akun login tersendiri — terpisah dari website ini.

Tujuan pengembangan

  • Menyediakan cara belajar struktur data yang visual dan dapat dicoba langsung.
  • Mengaitkan operasi pada objek dengan kode program yang setara.
  • Memberi siswa ruang berlatih dengan umpan balik langsung melalui tantangan.
  • Mengumpulkan data pemahaman awal dan akhir untuk mengevaluasi media ini.

Sasaran pengguna

Siswa kelas XI program keahlian Rekayasa Perangkat Lunak (RPL) / Pengembangan Perangkat Lunak dan Gim (PPLG), dengan guru atau peneliti sebagai pendamping.

Kompetensi yang dituju

  • Menjelaskan karakteristik array, linked list, stack, dan queue.
  • Membedakan prinsip akses langsung (indeks), LIFO, dan FIFO.
  • Mengidentifikasi operasi dasar tiap struktur dan hasilnya.
  • Mengaitkan operasi tersebut dengan penulisan kode sederhana.

Peran website ini

Website bukan pengganti game. Website berfungsi sebagai pintu masuk yang menyusun alur belajar: membaca materi ringkas, mengerjakan pre-test, mengakses game, mengerjakan post-test, lalu memberi evaluasi. Respons tes dan evaluasi tersimpan ke formulir dan spreadsheet masing-masing agar mudah dikelola oleh peneliti.

Catatan tentang klaim manfaat.

ALGOPLAY masih dalam tahap evaluasi. Website ini tidak menjanjikan kenaikan nilai atau efektivitas tertentu; hasil pre-test, post-test, dan evaluasi akan menjadi dasar penilaiannya.

  • Array — indeks, elemen, akses langsung
  • Linked List — node, pointer, head/tail
  • Stack — push, pop, LIFO
  • Queue — enqueue, dequeue, FIFO
