Buka tautan unduhan Baca panduan

Tautan dibuka di tab baru melalui Google Drive. Unduhan dikelola oleh browser/perangkatmu; halaman ini tidak dapat memastikan unduhan selesai.

Jika Drive meminta izin akses

Klik Request access / Minta akses, lalu beri tahu pendamping agar permintaanmu disetujui. Jangan mencari file dari sumber lain.

Langkah pemasangan

  1. Unduh file dari tautan di samping sampai selesai.
  2. Buka file yang terunduh. Pada Android pilih Pasang; pada Windows ekstrak lalu jalankan berkas aplikasinya.
  3. Jalankan game, masuk ke akun game, dan mulai dari Dashboard.
  4. Mainkan keempat materi. Tidak ada batas waktu; progres tersimpan di akun game.

Catatan keamanan & kompatibilitas

  • Unduh hanya dari tautan resmi di halaman ini.
  • Sistem operasi mungkin menampilkan peringatan untuk aplikasi di luar toko resmi; itu normal untuk aplikasi penelitian, tetapi pastikan sumbernya memang tautan ini.
  • Kompatibilitas game diuji terpisah dari website; detail perangkat yang didukung akan ditambahkan setelah pengujian.

Sudah selesai bermain?

Tandai tahap ini di browser-mu, lalu lanjut ke post-test. Penandaan ini hanya pengingat lokal, bukan bukti resmi.
