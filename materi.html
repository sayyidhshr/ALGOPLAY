01 · Array

Array

Array adalah kumpulan elemen bertipe sama yang disimpan berurutan dan diberi nomor indeks. Indeks dimulai dari 0, sehingga elemen ke-3 berada pada indeks 2.

Karakteristik

  • Ukuran ditentukan saat dibuat (pada array statis).
  • Setiap elemen dapat diakses langsung melalui indeksnya, misalnya nilai[2].
  • Elemen tersimpan berdampingan, seperti gerbong yang dirangkai pada satu lokomotif.

Operasi dasar

  • Membuat array dengan ukuran tertentu.
  • Mengisi atau mengubah nilai pada indeks tertentu.
  • Mengakses nilai pada indeks tertentu.

Di dalam game: materi Array divisualkan sebagai rangkaian gerbong kereta. Setiap gerbong adalah satu elemen dengan nomor indeksnya.

02 · Linked List

Linked List

Linked list tersusun dari node. Setiap node menyimpan data dan sebuah pointer/referensi ke node berikutnya (next). Node pertama disebut head, node terakhir menunjuk ke null.

Karakteristik

  • Ukuran dapat bertambah atau berkurang kapan saja.
  • Elemen tidak harus berdampingan di memori — yang penting pointernya benar.
  • Untuk mencapai node ke-n, penelusuran dimulai dari head.

Operasi dasar

  • Menambah node di akhir (atau di posisi tertentu) dengan memperbarui pointer.
  • Menghapus node dengan mengalihkan pointer node sebelumnya.
  • Menelusuri dari head sampai null.

03 · Stack

Stack

Stack mengikuti prinsip LIFO — Last In, First Out. Elemen yang terakhir dimasukkan adalah yang pertama dikeluarkan. Bayangkan tumpukan burger: lapisan paling atas selalu yang paling baru.

Operasi dasar

  • push — menaruh elemen di puncak (top).
  • pop — mengambil elemen dari puncak.
  • peek — melihat elemen puncak tanpa mengambilnya.

Contoh penerapan: tombol undo, tumpukan pemanggilan fungsi, pengecekan tanda kurung yang berpasangan.

04 · Queue

Queue

Queue mengikuti prinsip FIFO — First In, First Out. Elemen yang pertama masuk adalah yang pertama keluar, persis seperti antrean di loket.

Operasi dasar

  • enqueue — menambahkan elemen di belakang (rear).
  • dequeue — mengeluarkan elemen dari depan (front).
  • front — melihat elemen terdepan tanpa mengeluarkannya.

Contoh penerapan: antrean cetak dokumen, penjadwalan tugas, antrean pesan.
